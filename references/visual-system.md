## 1. 识别公式

画面必须同时满足以下四层，不能只满足其中一层：

1. **符号层**：用少量圆、椭圆、矩形、梯形、三角和负形构成一眼可辨的剪影。
2. **色彩层**：角色拥有稳定身份色；背景更粉彩、更灰化，避免抢夺主体。
3. **表演层**：头、眼、眉/眼皮、嘴和全身倾斜共同表达情绪，不能只换嘴型。
4. **图形层**：速度、力量和情绪用放射线、色场、白闪、星芒、轮廓变形和极端裁切直接可视化。

若画面只有“大眼睛＋黑描边”，但仍保留写实头身、复杂衣褶、真实透视或立体光影，应判定为不合格。

## 2. 媒介、线条与色块

- 使用 1990 年代末美式电视 2D 赛璐珞/数字平涂动画感。
- 外轮廓使用稳定、清楚、接近均匀的深黑粗线；重要轮廓可略粗，内部结构线显著减少。
- 轮廓转折利落，弧线圆润但不软塌；几何形之间允许直接相切或嵌套。
- 角色以纯色平涂为主，通常没有明暗塑形；必要阴影只用一档大色块。
- 背景可以有极少的单向渐变、透明雾层或纸面柔化，但不得出现 PBR 高光、真实反射、皮肤次表面散射和电影体积光。
- 纹理只在功能需要时出现：墙面少量砖线、污渍、裂纹，城市少量窗格，机械少量面板线。禁止平均铺满噪点和装饰。
- 线条与色块必须干净，不模拟铅笔草稿、蜡笔、油画笔触或水彩洇染。

## 3. 色彩架构

### 3.1 角色身份色

每个主要角色只分配一个主身份色和 1–2 个辅助色。主色必须贯穿眼睛、服装、尾迹、能量或专属背景，使角色高速运动时仍可识别。

| 功能 | 推荐色域 | 用法 |
| --- | --- | --- |
| 热情/领导 | 珊瑚红、玫红、暖橙红 | 主角、命令、正面冲击、中心位置 |
| 轻快/乐观 | 天蓝、青蓝、淡蓝 | 高位飞行、圆弧动作、清亮音色 |
| 强硬/怀疑 | 草绿、黄绿、深绿 | 直线突进、短句、近身攻击 |
| 反派/危险 | 黑、深红、酸绿、紫、脏黄 | 尖锐轮廓、阴影色场、腐蚀或威胁 |
| 城市日常 | 奶油黄、粉桃、灰蓝、鼠尾草绿 | 低对比背景与公共空间 |

这些是功能色域，不要求机械复制固定色值。若用户已有主色，以用户颜色为准，并为尾迹、能量和专属动作背景建立同色系扩展。

### 3.2 主体与背景分离

- 主角颜色更纯、更亮、更少层级。
- 背景颜色偏粉彩、偏灰、对比更低，黑色面积更少。
- 危机时可以把整场景切换成单一高饱和色场，例如红、粉、紫或酸绿，再用黑白剪影组织信息。
- 黑色主要用于轮廓、眼睛、阴影剪影和危险区域；不要把全画面压成暗黑电影光。
- 白色用于眼睛高光、闪白、冲击核心和空间留白，必须保留足够干净面积。

## 4. 角色几何设计

### 4.1 儿童/小型英雄

- 头部约占全身高度的 50%–65%，近圆形或略扁椭圆。
- 双眼合计可占脸宽的 60%–80%；黑色瞳区巨大，彩色虹膜环与单个白色高光维持可读性。
- 默认不画写实鼻梁；鼻子可省略或只用极小符号。
- 嘴位于脸下部，用短弧、小圆口、豆形口或夸张黑色口腔切换。
- 身体是短梯形、胶囊或简化连衣裙形；腰、胸、骨盆不做写实结构。
- 四肢是短胶囊或圆柱；手可简化为无指端头，脚可用黑色鞋块。用户角色有关键手部道具时，保留最少必要抓握结构。
- 发型、耳朵、帽子或头饰必须形成一个强剪影大形，不用细碎发丝。
- 服装压缩为 2–4 个大色块和一个代表性符号；不画复杂缝线、褶皱与材质。

### 4.2 成人、公众与喜剧配角

- 可使用更长、更角、更不均衡的比例，与小型英雄形成尺度反差。
- 头可为方形、楔形、长椭圆或不规则几何；鼻、下巴、发型和肩线可被极端放大。
- 躯干用长矩形、倒梯形、球形或豆形；腿和手臂可像折线或管状结构。
- 手只在必要时画 3–4 个块状手指；避免写实关节和皮肤细节。
- 同一群众场景中，用不同头形、肩宽、身高、姿势方向和单一服装色区分，不堆面部细节。

### 4.3 自恋英雄、劲敌与权威

- 放大胸肩、下巴、发型或披风，形成“标志先于人物”的夸张剪影。
- 使用正面、低机位、中心对称和占满画面的姿态制造虚假伟岸。
- 让造型本身暴露性格：过长下巴、过宽胸膛、过亮徽记、过度整齐发型。
- 真正行动能力由动作证明，不要只凭肌肉、披风或台词判定。

### 4.4 反派与怪兽

- 优先不对称、尖齿、长口、巨大眼或极小眼、夸张耳/角/爪和不稳定重心。
- 将危险集中在 2–3 个大形：巨大口腔、武器、尾锤、机械拳或发光核心。
- 牙齿常用白色三角阵列，口腔是整块深黑；无需写实牙龈和唾液。
- 怪兽表皮以 2–4 个纯色块和少量斑点/鳞片符号表示，禁止真实毛孔、湿润材质和复杂生物纹理。
- 大型机械用桶状躯干、可伸缩管状肢体、方拳、圆顶驾驶舱和少量面板，运动偏笨重的 pose-to-pose。

### 4.5 三人或多人战队

- 不强制三人；只有用户已有三人或明确要三人组时才使用。
- 建立共同语法：相近头身比、相同服装结构或统一黑白基底。
- 建立个体差异：不同身份色、发型/耳形、眼形、中心/左右位置、动作方向和情绪倾向。
- 队形优先三角、浅 V 字、正面横排或一前两后；领导者不一定永远居中，按剧情功能调整。
- 镜像对手可保留同色相映射，但用角度、发型、服装方向、眼皮和动作节奏反转性格。

## 5. 身份锁定与风格转译

### 5.1 必须锁定的锚点

从上传图或文字中提取：

1. 角色数量与相互关系
2. 脸型、物种和关键面部标记
3. 发型、耳朵、角、帽子或头饰轮廓
4. 服装主形与不可丢失的符号
5. 主色与辅助色
6. 关键道具和能力来源
7. 姿势意图、视线和屏幕位置
8. 场景结构、出入口和主体尺度

### 5.2 允许压缩的内容

- 将发丝压成一到三个发型色块。
- 将布料纹理压成纯色或一个图案符号。
- 将写实五官压成眼、眉/眼皮、口和一条必要鼻线。
- 将金属、皮革、毛发、玻璃等材质压成颜色与轮廓差异。
- 将复杂背景压成前景遮挡、中景行动区和远景剪影三层。

### 5.3 不允许的变化

- 不因“大眼比例”而改变年龄、种族、物种或角色身份。
- 不把单人强制复制成三人，不把群像合并成同一模板。
- 不丢失残障器具、宗教/文化服饰、职业道具或剧情关键标志。
- 不凭空新增翅膀、披风、武器、手脚或超能力。
- 不让颜色映射在镜头间漂移。

## 6. 场景设计

### 6.1 城市外景

- 使用中世纪现代主义、装饰艺术与儿童图形设计混合的城市轮廓。
- 建筑由直立矩形、梯形、圆顶、尖塔和少量窗格组成；透视可以轻微夸张，但空间方向必须清楚。
- 天空保持大面积纯色或轻微渐变；云可用白色团块或长弧线。
- 远景楼群细节低、颜色浅；中景保留行动通道；前景用一到两个大形建立尺度。
- 破坏场景用倾斜楼体、裂口、烟柱和少量碎块符号，不模拟真实坍塌物理。

### 6.2 家庭与学校

- 使用白、奶油、淡蓝、粉桃、鼠尾草绿等明亮色。
- 家具和设备只有清楚轮廓与功能色，减少材质和杂物。
- 用圆窗、弧形道路、胶囊树、几何书架、简单电话或电视建立世界观。
- 让房间像表演舞台：主体区空，入口、电话、屏幕或桌面是剧情触发点。

### 6.3 监狱、实验室与反派空间

- 监狱使用冷灰蓝、脏橄榄、黑色栅栏和局部污渍；构图更窄、更压迫。
- 实验室使用奶油色或灰蓝底，玻璃器皿和机器压缩为圆、管、按钮和显示块。
- 反派空间可切换为深红、紫黑或酸绿单色场，让脸、手和道具在高对比中突出。
- 污秽喜剧用波浪臭气、黏液色块、苍蝇/蜗牛等少量符号表达，不做写实脏污。

### 6.4 公共空间与人群

- 用 5–12 个不同剪影代表人群，不需要绘制每个个体。
- 人群可以像合唱队一样同时转头、惊呼、后退或围拢。
- 新闻、电视或演讲场景用屏幕框、麦克风、讲台和闪光灯快速建立语境。
- 群众态度可通过整体色场、队形和同步动作变化表现，而非大量解释性台词。

## 7. 构图与景别

- **建立镜头**：远景城市或单一地标，水平线简洁，主体通常位于中心或三分点。
- **队形镜头**：正面或轻俯视，角色形成三角/V 字；留出明确飞行方向。
- **对话镜头**：中近景锁定，身体大多持帧，通过眼皮、嘴型、头部倾斜和手势完成表演。
- **威胁镜头**：低机位、广角式夸张比例、黑色前景或巨大口腔/拳头压入画面。
- **情绪镜头**：眼睛、嘴、电话、按钮、徽记或武器的极端特写；允许裁掉大量头部。
- **动作镜头**：清楚侧向行动轴、对角线飞行和大面积负空间；主体可以很小，尾迹负责读方向。
- **结果镜头**：爆炸云、墙面撞击符号、破洞、烟尘或角色落定姿势必须完整入画。

避免连续使用相同景别。典型节奏是：远景建立 → 中景行为 → 近景态度 → 极端特写转折 → 大远景爆发 → 中景结果。

## 8. 图形特效

| 功能 | 视觉构成 | 动画方式 |
| --- | --- | --- |
| 高速飞行 | 身份色色带、白色中心线、少量残像 | 先短持帧，再瞬间拉成长条并离画 |
| 冲击 | 白闪、星形/锯齿爆点、单帧黑白剪影 | 1–3 帧冲击后短命中停顿 |
| 爆炸 | 白黄核心、橙红外圈、贝壳状烟云 | 快速膨胀、短持、分裂成少量烟团 |
| 能量束 | 纯色直线或锥形束、白色芯、少量电弧 | 锁定方向，不做随机粒子飘散 |
| 化学/邪恶能量 | 酸绿锯齿光环、波浪臭气、气泡或黏液块 | 从明确容器/身体/装置发出 |
| 情绪强调 | 放射线、同心圆、单色背景、眼睛或嘴填满画面 | 与台词重音或反应 take 同步 |
| 眩晕/失败 | 星星、螺旋眼、扁平烟圈、墙面撞击图标 | 短暂出现并快速恢复身份轮廓 |

特效不得把角色遮成不可辨认的光团。真实运动模糊、镜头光晕、粒子景深和体积烟雾均不属于默认语言。

## 9. 片头、标题与片尾

只有用户明确要求时启用。

- 片头可使用高对比红/黑/白色场、角色剪影、反派拼贴、快速横向飞行、心形/星形/爆点和硬切。
- 单集标题卡可使用黑色或单色背景、白色凝练倾斜字形、角色剪影或一件剧情道具；保持简洁。
- 片尾可使用同心心形、队伍合影、城市恢复或一个动作补刀。
- 所有文字必须使用用户的原创片名与署名；不复刻现有 Logo、固定字标、主题曲歌词和原作排版。
- 若用户未提供文字，不要让模型生成不可读的伪文字。

## 10. 常见退化与修正

| 退化结果 | 原因 | 修正 |
| --- | --- | --- |
| 现代 Q 版贴纸 | 只强调可爱大眼 | 增加稳定粗黑线、极端几何、成人/怪兽比例反差和动作色场 |
| 日漫萌系 | 使用尖下巴、发丝、鼻梁和阴影 | 删除写实五官与发丝，压成圆头、整块发型和纯色平涂 |
| 3D 卡通 | 使用材质、高光、景深和体积光 | 改为二维色块、无表面光泽、无真实阴影与无镜头虚化 |
| 泛 UPA 海报 | 只有几何背景、角色眼睛太小 | 恢复超大眼、黑色瞳区、卡通口型和高速英雄动作 |
| 全程霓虹 | 把能量色当成环境光 | 背景回到粉彩，霓虹只在短促特效中出现 |
| 画面太空 | 背景被过度删除 | 加入地标、行动轴、入口与 1–3 个功能道具，仍保持低细节 |
| 画面太满 | 平均添加窗格、纹理与人群 | 只保留剧情需要的大形，让负空间承担速度与可读性 |
