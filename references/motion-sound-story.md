## 1. 总节奏

这种动画的动感来自**速度反差**，不是全程丝滑：

- 日常对话：身体持帧 0.5–2 秒，只动眼皮、瞳孔、嘴、头部或一只手。
- 情绪建立：先用一个清楚姿势持住，让观众读懂态度。
- 决定瞬间：突然切近景、单色背景或放射线。
- 高速行动：6–24 帧内完成冲刺、撞击、绕飞或离画。
- 命中：1–3 帧白闪/星芒/剪影，随后 2–8 帧命中停顿。
- 结果：回到清楚中景或大远景，让烟尘、破洞、落地或表情成立。

动画输出可保持 24 fps，但普通表演主要一拍两格或三格，高速爆发和冲击短暂一拍一格。禁止全程插帧造成匀速漂浮、果冻肢体和无重量滑行。

## 2. 有限动画表演

### 2.1 对话动作

- 身体与背景保持稳定，以 2–5 个关键口型配合短句。
- 用眼皮高度、瞳孔方向、眉/额线、头部倾斜和嘴角方向形成态度。
- 小型英雄的手臂动作应短而明确：指、叉腰、抱臂、举拳、摊手；不要做复杂写实手势。
- 成人配角可以用长手臂、方手、下巴和胸肩进行更夸张的节奏性动作。
- 一句台词只配一个主要动作，不要在每个字上随机摆动。

### 2.2 反应 take

按以下顺序编排：

1. 预反应持帧
2. 眼睛/瞳孔先变化
3. 头或身体瞬间后仰、压缩或倾斜
4. 嘴型跳到极端
5. 短持 4–12 帧
6. 回到新的决定姿势

惊讶可以让眼睛扩大、口腔变成整块黑形；愤怒可压低眼皮、身体前倾、拳头靠近身体；尴尬或怀疑可只移动瞳孔和一侧眼皮。

### 2.3 表情近景

- 允许眼睛、嘴、牙齿、电话听筒、按钮或徽记占满画面。
- 极端近景应承担转折、威胁或笑点，不是装饰。
- 推入巨大口腔时，牙齿可成为白色三角边界，黑色口腔变成抽象空间。
- 一次极端近景之后应切回空间结果，避免连续多镜失去方位。

## 3. 高速动作语法

每个关键动作使用以下七步中的至少五步：

1. **预备**：角色反向压缩、眼神锁定、拳头收回或身体短暂停住。
2. **启动**：1–3 帧突然拉伸，动作方向明确。
3. **图形化运动**：身份色色带、速度线、残像、长椭圆或纯色剪影。
4. **接触**：拳、身体、能量束或道具到达明确接触点。
5. **冲击帧**：白闪、星芒、锯齿爆点、反色或黑白剪影。
6. **命中停顿**：画面短暂停住，让力量可读。
7. **过冲与落定**：对手离画、撞墙、烟尘扩散，主体回到清楚姿势。

禁止把动作写成“角色优雅地连续旋转并缓慢释放能量”。应写明方向、持续帧感、接触点和结果。

### 3.1 速度表现

- 起步几乎没有自然加速度，常从静止直接进入高速。
- 高速中身体可简化成头部/拳头/身份色条，细节暂时消失。
- 离画后保留尾迹 2–6 帧，再快速清除。
- 转向用折线、直角、急弧或一帧停点，不用真实飞行惯性。
- 追逐路径以水平、垂直和强对角为主，空间简单但方向连续。

### 3.2 冲击表现

- 轻击：小星芒＋短啪声＋极短停顿。
- 重击：白闪＋锯齿爆点＋低频重音＋对手快速离画。
- 城市级破坏：远景闪白/爆炸云＋建筑剪影倾斜＋烟尘结果镜头。
- 喜剧撞击：墙面出现平面破洞或红色爆点，角色可暂时压扁/拉长，但迅速恢复。

## 4. 飞行、战斗与巨物

### 4.1 飞行

- 身体保持简洁刚性，头部指向前进方向，手臂前伸、后收或贴身。
- 角色身份色形成平行尾迹；白色芯线可增强速度。
- 团队飞行使用浅 V 字、三角或错位平行队形。
- 进入战斗前可由队形镜头切到每个角色的单色放射背景和专属姿势，再回到整体空间。
- 飞行结束必须有减速姿势、悬停姿势、落地或离画结果，不在半途结束。

### 4.2 小型英雄战斗

- 单镜只安排一个主要攻击：直拳、头撞、踢、身体冲撞、能量束、抓住旋转或队形夹击。
- 角色轮流承担清楚功能，避免三人同时在画面中央乱打。
- 每个角色的攻击方向、尾迹色和声音动机保持一致。
- 团队高潮优先“分散攻击 → 怪兽反制 → 重新集结 → 同步一击”，而非重复三次相同攻击。

### 4.3 镜像对手

- 先用相似配色和队形建立“对应关系”，再用眼皮、发型、姿态、服装方向和动作质量表现反转。
- 可采用逐个单人卡：每个角色在专属放射背景中完成一句口号或一个姿势，随后合体冲出。
- 镜像方的力量应在行动中证明；不要只靠旁白说“他们一样强”。
- 交锋时保持一对一颜色对应，高潮再打乱配对或形成团队反转。

### 4.4 巨型怪兽与机器人

- 用低机位和极简城市远景建立尺度。
- 巨物动作更少、更重：抬臂持帧、身体转向、一步落地、拳头压下、尾锤横扫。
- 环境破坏通过 2–4 个关键姿势、爆炸覆盖和结果镜头完成，不模拟连续真实物理。
- 小型英雄用高速直线和弧线绕过巨物；巨物用大面积黑形、拳/口/尾巴封锁画面。
- 最终击败必须有清楚因果，例如击中发光核心、利用巨物自撞、同步破坏支点或把攻击反射回去。

## 5. 运镜与剪辑

### 5.1 基本原则

摄影机负责读清信息，不模拟真人电影设备。默认使用：

- 锁定远景/中景
- 简单水平或垂直平移
- 轴向快速推近/拉远
- 低机位威胁镜头
- 俯视队形与空间关系
- 极端特写
- 跟随尾迹的短促侧向追踪

避免无人机环绕、长焦景深、手持晃动、复杂稳定器走位和写实镜头呼吸。

### 5.2 镜头功能

| 叙事功能 | 推荐镜头 |
| --- | --- |
| 建立城市/危机 | 远景地标＋硬切到破坏源 |
| 引入新人物 | 脚/徽记/披风插入 → 低机位全身 → 群众反应 |
| 表达怀疑 | 中近景队形 → 单人眼神特写 → 反打 |
| 宣布行动 | 正面队形＋短推近＋放射背景 |
| 高速追逐 | 侧向跟拍、前方倒退式平移或固定镜头让色带穿过 |
| 重大冲击 | 接触特写 → 单帧闪白 → 大远景结果 |
| 揭露骗局 | 道具/破绽特写 → 人物僵住 → 群众整体转向 |
| 结尾补刀 | 中景短反应、静止道具或同心图形收束 |

### 5.3 剪辑节奏

- 对话段落镜头通常 1.5–4 秒；若身体持帧，可用眼神和口型维持节奏。
- 动作段落镜头可缩短到 0.25–1.5 秒，重大结果镜头再延长到 1–3 秒。
- 用硬切为主；闪白、星芒、单色卡、心形/圆形图形可作短转场。
- 同一动作不要在多个镜头重复完整过程；切镜应发生在预备、接触或结果节点。
- 最后一镜必须在动作、台词或表情落点完成后再结束。

## 6. 台词与旁白

### 6.1 台词原则

- 句子短，通常一句只完成“态度、命令、质疑、炫耀、揭露、笑点”中的一项。
- 角色先行动，台词补充性格；不要让人物解释刚刚发生的可见动作。
- 使用明确动词和对立词，避免抽象长句。
- 允许快速打断、三人依次接话、公众齐声反应和反派自我重复。
- 笑点常来自“郑重宣言后立刻被事实打脸”或“公众态度瞬间反转”。

### 6.2 角色声音功能

| 功能 | 语言与表演 |
| --- | --- |
| 领导者 | 句式完整、节奏稳、命令清楚，情绪爆发时音高上扬但不失控制 |
| 乐观者 | 音色明亮、开放元音多、先相信后惊讶，台词带真诚而非幼稚 |
| 强硬者 | 句子最短、辅音硬、质疑直接，情绪常通过停顿和眼神完成 |
| 自恋劲敌 | 声音宽、姿态大、反复自夸，危机来临时节奏破碎或音量骤降 |
| 反派 | 戏剧化、快速、喜欢列举计划和重复关键词，尾句常变成咆哮 |
| 市民/公众 | 合唱式惊呼、夸赞、责怪和道歉，态度变化快，形成社会讽刺 |

不要复制原作固定口号或经典台词。根据用户角色重新设计语言习惯。

### 6.3 旁白

- 完整单集可用热情、正经得近乎夸张的故事书式旁白建立城市、危机和结尾。
- 开场旁白只需 1–3 句：地点 → 今日异常 → 主角行动。
- 结尾旁白只需 1–2 句：危机解决 → 带双关或反差的短总结。
- 短视频中旁白与角色台词不要同时拥挤；15 秒通常二选一。
- 不复刻现成开场句、结束句或播音腔录音。

## 7. 音乐系统

音乐必须原创，只迁移配器、节奏与声画关系，不引用主题曲旋律。

### 7.1 音乐色板

| 场景 | 速度与配器 | 功能 |
| --- | --- | --- |
| 片头/出击 | 150–180 BPM；快速鼓组/碎拍、失真或冲浪吉他、合成贝斯、铜管/风琴短音 | 建立高速、顽皮、英雄感 |
| 城市日常 | 100–135 BPM；轻鼓、贝斯、木琴/电颤琴、短弦或明亮合成器 | 保持活跃但不压对白 |
| 英雄亮相 | 120–155 BPM；军鼓、铜管重音、上行吉他/合成器动机 | 放大姿态，可故意过度宏大 |
| 反派计划 | 70–115 BPM；低音铜管、巴松/低木管、风琴、半音下行、稀疏打击 | 阴险、滑稽、机械感 |
| 喜剧误会 | 100–145 BPM；拨弦、木块、弱音铜管、滑音、突然休止 | 支持反应 take 和打脸 |
| 怪兽战斗 | 145–180 BPM；重鼓、断奏吉他/合成器、低音脉冲、铜管爆点 | 推动追逐与连续攻击 |
| 化学/诞生 | 90–140 BPM；上行琶音、颤音琴/铃、酸性合成器、低频脉冲与逐层加速 | 从诡异蓄能到突然揭示 |
| 温情/收束 | 75–110 BPM；短弦、钟琴、电颤琴和轻贝斯 | 只停留数秒，避免煽情 |

### 7.2 声画同步

- 角色专属动作对应稳定的 2–5 音动机或音色，不要求连续播放。
- 眼神切换、手势、飞出、命中、落地和表情反应应有清楚音乐落点。
- 大冲击前允许 4–12 帧短静默或削弱配器；冲击后让低频和尾响出现。
- 反转时可突然切断宏大音乐，改成单个木块、低音或尴尬休止。
- 对话时减弱鼓和中频旋律，不覆盖辅音；关键短句后再进入动作重音。
- 15 秒短片只建立一个主要音乐主题；30 秒可有日常、危机、高潮三段变奏。

## 8. 拟音系统

### 8.1 动作拟音层

一次重击可按以下层级组合：

1. 预备：衣物/空气短收紧、拳头蓄力或低频吸入
2. 运动：高频 whoosh、喷射或色带掠过
3. 接触：干脆啪/砰、金属或肉感主击
4. 重量：低频 thump 或短次低频
5. 结果：碎块、烟尘、墙体、弹簧或机械尾响
6. 反应：短叫声、喘息、群众吸气或一拍静默

### 8.2 常用声音

- 飞行：明亮喷射式掠过声，按身份色/角色音色区分。
- 激光/能量：短起音、稳定纯音芯、接触爆点；不要长时间科幻嗡鸣。
- 爆炸：短促卡通爆点＋低频＋少量碎片，不做写实战争混响。
- 巨型机械：伺服、弹簧、金属卡合、重脚落地，节奏清楚。
- 化学能量：气泡、黏液、电子颤音、上升哨音、突然白闪。
- 电话/电视/警报：作为剧情触发点，声音一出现就让角色反应。
- 喜剧：木块、滑音、弹簧、软挤压、短号弱音；一镜最多一个主笑点声。

声音应干净、前景化、短尾音。不要用现代电影预告片式长低频轰鸣覆盖整个短片。

## 9. 剧情引擎

### 9.1 稳定骨架

1. **城市常态**：用一个地标、公众活动或旁白快速建立秩序。
2. **异常出现**：新英雄、镜像对手、怪兽、反派计划或误会打破秩序。
3. **主角立场**：团队成员对异常产生不同判断。
4. **第一次证明/误判**：公众或主角暂时相信错误结论。
5. **第二次升级**：问题扩大到城市、关系或身份层面。
6. **揭露/反转**：行动暴露骗局、弱点或真正动机。
7. **团队行动**：成员按性格和能力分工，不靠单一万能招。
8. **高潮回收**：前面建立的道具、规则、颜色对应或性格缺点决定结果。
9. **短促收束**：公众态度、旁白或角色反应完成讽刺性补刀。

### 9.2 “公众劲敌”机制

适合虚假英雄、网红、明星、竞争对手或取代主角的人：

- 夸张亮相与公众热捧
- 主角怀疑但暂时缺少证据
- 劲敌通过摆拍、抢功或话术维持形象
- 真危机迫使其行动
- 一个可见破绽暴露虚假
- 主角用协调行动解决问题
- 公众迅速转向，形成社会讽刺

不要把劲敌写成纯坏人；虚荣、胆怯、依赖掌声或缺乏真实能力会更符合喜剧结构。

### 9.3 “镜像战队诞生”机制

适合复制体、敌对搭档、反英雄团队或能力镜像：

- 反派因失败而寻找“同等但相反”的力量
- 用一个荒诞、具体、可视化的制造规则
- 制造过程逐层升级，兼具恶心/机械/化学喜剧
- 新战队以颜色对应和轮廓反转逐个亮相
- 每人展示一个不同性格动作
- 合体队形确认关系后立即出击

不要照搬原作配方、角色名称、造型和后续战斗结局。根据用户世界观设计新的制造逻辑。

### 9.4 主题

优先选择简单而可行动证明的主题：

- 真正的勇气来自行动，不来自名声
- 团队差异能形成互补
- 复制外形不等于复制关系
- 公众判断容易被表演操纵
- 自信与自恋、力量与责任之间的差异

避免长篇说教；让高潮行动和结尾反差表达主题。

## 10. 时长结构

### 10.1 15 秒

- 0–2 秒：图形化城市/角色钩子
- 2–5 秒：异常或对手出现
- 5–9 秒：第一次交锋/误判
- 9–13 秒：反转＋团队高速行动
- 13–15 秒：落定姿势或喜剧补刀

### 10.2 30 秒

- 0–3 秒：城市与主角状态
- 3–7 秒：新问题/劲敌/怪兽出现
- 7–12 秒：公众或团队第一次反应
- 12–18 秒：问题升级，主角受挫
- 18–23 秒：揭露弱点或重新分工
- 23–28 秒：颜色分明的团队高潮
- 28–30 秒：结果与短补刀

### 10.3 8–11 分钟单集段落

- 0:00–0:45：开场行动或城市常态
- 0:45–1:30：异常与标题/主题建立
- 1:30–3:30：角色态度和第一次误判
- 3:30–5:30：第二次升级与关系冲突
- 5:30–7:30：真相/弱点暴露
- 7:30–9:30：动作高潮与回收
- 9:30–11:00：结果、公众反应、旁白/补刀

按实际总时长成比例调整，不为了填满结构加入无关角色。

## 11. 连续性与安全边界

- 保持角色主色、眼形、发型/耳形、服装大色块和能力颜色跨镜一致。
- 保持屏幕方向；角色向右追逐时，不经建立镜头不要突然改为向左。
