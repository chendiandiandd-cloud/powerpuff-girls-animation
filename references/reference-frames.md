## 1. 使用原则

这些图片从用户提供的两集样片中选取，只用于校准可观察的视觉语法。画面中的字幕、水印、频道角标、原作人物、服装、道具和逐镜构图都不是要复制的风格元素。

执行涉及图片、分镜或视频视觉的任务时：

1. 先查看总参考板 [reference-board.jpg](../assets/reference-board.jpg)，建立整体色彩、几何与空间印象。
2. 再按任务查看 2–4 张单帧；动作或视频任务额外查看 1–2 张动作序列参考板。不要把所有元素堆进同一结果。
3. 从单帧提取“比例、轮廓、色块、空间简化、动作极值、特效构成”这类规则；不要提取角色姓名、服装细节、标志性道具、字幕和 Logo。
4. 用户上传角色或场景时，以用户素材的身份与事实为最高锚点，参考帧只校准表达方法。

## 2. 总参考板

- [总参考板](../assets/reference-board.jpg)：12 张无字幕主体画面组成的 4×3 校准板，覆盖城市、道具、爆点、巨型机械、极端近景、住宅、监狱、化学能量、反派表情、镜像战队和单人动作卡。

总参考板用于快速判断结果是否同时具备：平面几何、粗黑轮廓、角色/背景色阶分离、有限动画极值、图形化力量和可读构图。

## 4. 动作序列参考板

动作序列参考板按时间从左到右、从上到下排列。它们用于观察姿势之间如何切换，不代表要逐帧复制。

| 编号 | 文件 | 可观察序列 | 应提取的运动规则 |
| --- | --- | --- | --- |
| M01 | [team intro sequence](../assets/motion-reference/01-team-intro-sequence.jpg) | 战队正面推进 → 敌方群像 → 横向对峙 → 单人轴向远离/接近 | 固定色场中用尺度突变、硬切和轴向运动制造速度；群像信息分批呈现 |
| M02 | [giant robot sequence](../assets/motion-reference/02-giant-robot-sequence.jpg) | 巨物持帧 → 转身/抬臂 → 拔起建筑大形 → 爆炸结果 | 巨物每次只改变一个大姿势；准备时间长于接触，破坏过程压缩为爆点和烟云 |
| M03 | [extreme push sequence](../assets/motion-reference/03-extreme-push-sequence.jpg) | 中近景吼叫 → 连续轴向推入口腔 → 牙齿/舌头抽象化 → 黑色吞满画面 | 推镜与嘴型极值同步；空间信息逐步删除，最后用纯黑完成情绪转场 |
| M04 | [team attack sequence](../assets/motion-reference/04-team-attack-sequence.jpg) | 三人集结持帧 → 平行高速飞行 → 分色光束命中 → 怪兽结果姿势 | 先确认队形，再分配颜色和攻击方向；接触以短闪光处理，随后立即回到全身结果 |
| M05 | [limited reaction sequence](../assets/motion-reference/05-limited-reaction-sequence.jpg) | 群体起始姿势持住 → 单色放射背景中的喊叫/上升 → 数帧口眼变化 | 身体可长时间保持大形，只让嘴、眼皮与少量高度变化完成表演；不要误判为静止故障 |

观察动作序列时，不根据抽帧间距推断精确逐帧时值；使用 [motion-sound-story.md](motion-sound-story.md) 中的节奏范围编排新动作。

## 6. 观察方法

查看单帧时依次回答：

1. 第一眼读到的是哪三个几何大形？
2. 主体色与背景色如何分层？
3. 黑色被用在轮廓、眼睛、口腔还是威胁剪影？
4. 镜头靠景别、机位、裁切还是色场表达力量？
5. 这是预备、启动、接触、冲击、反应还是结果姿势？
6. 删除原作角色与道具后，仍可迁移的规则是什么？

## 7. 禁止误读

- 不把烧录字幕、频道水印、标题字卡和片尾图形当作默认视觉元素。
- 不因参考板存在三人队形而强制用户角色变成三人。
- 不把粉色当作全局固定主色；它在样片中多承担主角身份、动作色场或背景对比功能。用户已有色彩时服从用户。
- 不把某一帧的扭曲当成角色常态造型；动作极值只在对应运动节点短暂出现。
- 不用参考帧证明应复制原作人物、台词、配方、Logo 或逐镜剧情。
